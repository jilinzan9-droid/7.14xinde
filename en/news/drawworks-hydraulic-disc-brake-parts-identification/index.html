Drawworks Disc Brake System Parts: Pads, Rotors and Actuators

Published by Pratt Oil · 15 October 2026

A request for a drawworks disc brake system can describe a complete assembly or one replacement component. Those are different purchasing decisions. Identify the installed brake first, then specify the pad, rotor, actuator or control item required. A clear component list helps a supplier review the inquiry against the original references instead of assuming that every part carrying a similar system name is interchangeable.

Start with the assembly designation

Use the complete brake model and the available equipment documentation. NOV’s catalog includes hydraulic caliper disc brakes among its drawworks technologies, alongside other arrangements. A broad description such as “rig brake” therefore does not identify the component. Keep the drawworks reference and the brake assembly reference together, while making clear which one appears on each document.

Organize the parts into separate groups

For purchasing purposes, distinguish friction pads, the disc or rotor, actuator components and hydraulic or control items. Pratt Oil’s hydraulic disc brake parts category includes a PS Series unit, rotor, friction pads and working or safety cylinder listings. These names help organize an inquiry; they do not establish that a component fits every PS model or another manufacturer’s assembly.

Preserve the documented actuation description

Manufacturer terminology can identify an important design difference. Svendborg Brakes distinguishes hydraulic-pressure-applied active calipers from spring-applied, hydraulically released calipers. Use the wording in the installed brake’s own documentation. This example explains why an exact designation matters; it should not be used to assign a particular operating principle to an unidentified PS component.

Prepare a reference for each requested component

For a pad or rotor, attach the original part reference and any existing drawing that defines its geometry and specification. For an actuator or control component, include the component identification and available assembly or circuit reference. State the drawing revision and quantity where known. A photograph can support the description, but it does not replace the specification or demonstrate a cross-model match. When several actuator or control items are listed, keep the position and reference associated with each line throughout the quotation review.

Separate a parts quotation from a system change

Tell the supplier whether you are sourcing an existing replacement item or discussing a complete assembly. Ask the quotation to identify the supplied component and the references used for matching it. Changes to the braking arrangement require a separate engineering review. For an existing-parts inquiry, start with the rotor or friction-pad listing and send the supporting equipment information.
