A drawing suffix can identify a different document configuration

The supplied files contain an F-series catalogue and a separate F-1000 parts list. Keep individual numbers within the selected edition

For the F-series page 14 configuration, the F-1000 discharge manifold is 6319-0025-00 and the suction manifold is 6319-0067-00. The piston rod is 6319-0075-00, while 6319-0071-10 identifies the piston-rod clamp. These examples show why a clear component description is as important as the number. A drawing reference, a complete fluid-end assembly and an individual replacement component are different levels of identification and should not be mixed on an order line.

Serial ranges remain important outside the fluid end

The catalogue index also separates F-1000 crosshead and lubrication references for serial numbers 1 through 11 from those beginning with serial number 12. A quotation for a power-end requirement therefore needs the serial context as well as the model. If a pump has been rebuilt, include the installed component markings and the drawing actually used for the rebuild. Similar numbers from a different edition are candidates for review, not confirmed substitutes.

Provide the full model, serial number, exact part number and quantity. State which source edition and assembly reference you are using, preserving the -00 or -02 ending as printed. For a specific requirement, use mud pump spare parts enquiries. Request confirmation of the exact reference and configuration before accepting a quotation. A catalogue entry does not establish stock, delivery time, manufacturer authorization or suitability for a particular pump.
