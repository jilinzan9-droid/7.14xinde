Technical details and source references

Confirm the installed model, drawing revision and dimensions before ordering. Catalogue quantities do not indicate current stock.

Reference documents and scope

  • S1 — EMSCO F-750 parts catalogue / manual. Reference file: EMSCO F-SERIES PARTSLIST.pdf.

PDF page numbers count from the first page of each reference file. Brand names identify the equipment or catalogue source. A listed number does not establish interchangeability, original-manufacturer authorisation, stock or a delivery commitment. Send the nameplate, complete reference, quantity and drawing revision for a parts review.

One drawing contains two different model selections

The supplied F-series catalogue combines EMSCO F-750 and FA-750 fluid-end information on PDF page 13. The shared heading makes it important to read each description carefully. Some rows explicitly distinguish the F-750 version from the FA-750 version. Removing the letter A from a purchasing request can therefore remove useful configuration information. Use the full model designation from the pump and preserve the original description associated with each requested part number.

Three F-750 references that help prevent confusion

The F-750 studded fluid end is listed as 6310-0091-00, its lower valve guide as 6310-0152-01, and its discharge manifold as 6310-0015-00. The neighbouring FA-750 entries use different numbers. These distinctions are more informative than a general request for an F-series fluid end. The source also identifies a common drawing reference, but that reference should not be substituted for the individual part number when only one component is required.

Do not make a piston selection from the model alone

The same sheet describes the piston as specified, leaving the actual selection dependent on additional information. A parts list can identify where an item belongs without determining every size or material choice for an installed pump. Ask for the exact component, bore where applicable, and the related drawing details. For a manifold enquiry, photograph its connections and existing marking. A shared catalogue page supports comparison; it does not establish blanket F-750 and FA-750 interchangeability.

Prepare a matching enquiry

State F-750 in full and supply the serial number, exact part number, quantity and drawing revision. Identify the item on the drawing if the number is unreadable.
