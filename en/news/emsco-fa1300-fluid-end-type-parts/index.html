EMSCO FA-1300 Parts: Identify Type I, Type 1-1/2 or Type II

Published by Pratt Oil · 20 October 2026

Distinguish three documented EMSCO FA-1300 fluid-end types and retain their exact assembly-number endings.

FA-1300 is not a complete fluid-end specification

The supplied catalogue has three separate FA-1300/FA-1600 fluid-end sheets: Type I, Type 1-1/2 and Type II. The model label identifies a family of references, while the type identifies the configuration being illustrated. Before requesting a complete fluid end or a retaining component, determine which sheet corresponds to the installed equipment. A photograph of the pump nameplate alone may not identify a fluid end that was replaced during an earlier rebuild.

Keep the three assembly references separate

Type I is listed as 6316-0240-00 on PDF page 16. Type 1-1/2 is 6316-0325-01 on page 17, and Type II is 6316-0325-00 on page 18. The final -01 and -00 endings must not be dropped or treated as alternative formatting. These are distinct source references, not an automatically confirmed interchange. Record the assembly and type together so that an individual part can be checked against the correct bill of materials.

Liner-retaining components also need a type check

The Type I sheet lists liner-lock body 6316-0243-00. The Type 1-1/2 and Type II sheets instead list body 6316-0335-00. Their related retaining pieces must also be read from the applicable drawing. A shared component description is not enough to select the correct configuration. For a liner or piston enquiry, add the installed bore and existing markings; do not derive an operating specification or a universal wear-parts set from the FA-1300 model name.

Prepare a matching enquiry

Provide FA-1300 in full, the serial number and the installed fluid-end type or assembly number. Mark the requested item on the corresponding drawing and state its quantity. Add photographs showing the retaining arrangement and component markings. If the type is uncertain, say so and provide dimensions for review rather than choosing the closest-looking number. Ask the quotation to identify the exact assembly context and any included associated pieces.

For a specific requirement, use mud pump spare parts enquiries. Request confirmation of the exact reference and configuration before accepting a quotation. A catalogue entry does not establish stock, delivery time, manufacturer authorization or suitability for a particular pump.
