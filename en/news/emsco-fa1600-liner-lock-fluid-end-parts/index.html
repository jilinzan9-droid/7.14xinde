Name the liner-retaining component precisely

An EMSCO FA-1600 enquiry for liner-lock parts can refer to the body, flange or two-piece ring. These have different entries in the supplied catalogue. A basic liner is another separate item, even when its number looks similar to a retaining component. Read the description and item location with the number. This is more reliable than copying several consecutive references into one order line called a liner-lock kit without defining its contents.

Compare Type I with Type 1-1/2 and Type II

The catalogue separates FA-1300/FA-1600 fluid ends into three types. Type I uses assembly 6316-0240-00; Type 1-1/2 uses 6316-0325-01; and Type II uses 6316-0325-00. The Type I liner-lock body is 6316-0243-00, while the other two cited sheets show 6316-0335-00. These type distinctions should travel with the enquiry. Neither the FA-1600 model label nor a partially transcribed assembly ending establishes that a component from another type will fit.

Do not confuse the basic liner with the flange

On the Type 1-1/2 sheet, 6316-0244-00 identifies the liner-lock flange, 6316-0333-00 the two-piece liner-lock ring, and 6316-0334-00 the basic liner. These references should remain distinct in a purchasing spreadsheet. The table below gives selected identification examples, not a universal conversion between configurations.
