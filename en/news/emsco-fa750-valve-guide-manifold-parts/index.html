Technical details and source references

Confirm the installed model, drawing revision and dimensions before ordering. Catalogue quantities do not indicate current stock.

Reference documents and scope

  • S1 — EMSCO FA-750 parts catalogue / manual. Reference file: EMSCO F-SERIES PARTSLIST.pdf.

PDF page numbers count from the first page of each reference file. Brand names identify the equipment or catalogue source. A listed number does not establish interchangeability, original-manufacturer authorisation, stock or a delivery commitment. Send the nameplate, complete reference, quantity and drawing revision for a parts review.

Preserve the letter A in an FA-750 enquiry

EMSCO FA-750 and F-750 references appear together in the historical F-series catalogue, but the drawing identifies different components for the two versions. A shortened description such as 750 pump parts can lose that distinction. Copy the full model from the equipment nameplate and attach the existing drawing when possible. The useful starting point is the installed configuration, rather than a visually similar photograph or a general family name.

Follow the model-specific rows

On PDF page 13, the FA-750 studded fluid end is 6310-0110-00. The lower valve guide is 6310-0118-00, and the discharge manifold is 6310-0015-01. Each is explicitly separated from the F-750 entry on the same sheet. Preserve the final suffix as well as the main number: the discharge-manifold distinction includes -00 versus -01. Similar-looking references should not be merged into one stock description without a documented matching review.

Define what accompanies the requested component

A lower valve guide, its associated bushing and a complete fluid-end requirement describe different purchasing scopes. The source drawing locates them within an assembly but does not make every adjacent component part of one order line. State whether seals, retaining pieces or other related items are required. The piston entry also needs a specification, so the model alone is insufficient for selecting a piston size. Add the bore and markings of the installed components to the enquiry.

Prepare a matching enquiry

Provide FA-750 in full, its serial number and the exact references required. Mark each item on the source drawing and state the quantity separately. Attach photographs showing the part markings and mating interfaces, with dimensions where identification is incomplete. For a manifold, include connection details; for a piston or liner, include the installed bore. Ask for any proposed substitute to be identified separately with the basis of its compatibility confirmed.

For a specific requirement, use mud pump spare parts enquiries. Request confirmation of the exact reference and configuration before accepting a quotation. A catalogue entry does not establish stock, delivery time, manufacturer authorization or suitability for a particular pump.
