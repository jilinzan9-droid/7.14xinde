Use the FB-1300 parts list as an assembly map

The supplied National-Oilwell FB-1300 parts list is identified as EPL 1340, dated October 2000. Its index separates the general assembly from fluid-end, pinion, crankshaft, crosshead and lubrication sections. This hierarchy is useful when a repair enquiry contains only a model name and a photograph. First identify which assembly the item belongs to, then retain the exact component number and drawing context. The historical document date is not a statement about current production or availability.

General assembly and fluid end are different references

The FB-1300 index lists 6317-0200-00 for the general assembly and 6316-0375-00 for the fluid end. The fluid-end sheet then identifies its own components, including the studded fluid end, piston rod, liner lock and liner thread ring. An enquiry for one of those pieces should not use the general-assembly number as though it identified the loose item. Similarly, a complete assembly request should define the supply scope instead of assuming every pictured component is included.

Preserve optional and left/right distinctions

The index includes optional piston-and-liner references distinguished as left hand and right hand. Keep those designations with the number when they apply to the installed configuration. Do not simplify a pair of optional entries into one universal assembly. The catalogue supports a structured identification process, but it does not prove that every FB-1300 and FB-1600 component is interchangeable merely because a particular fluid-end reference appears in both source sets.
