F-Series Mud Pump Crosshead Parts and Drawing Numbers

Published by Pratt Oil · 2 November 2026

A mud pump crosshead inquiry should identify the body, crosshead pin and guide plates separately. The F-series parts table lists different references for these items. Sending the pump model and complete drawing number helps distinguish a single replacement component from a wider assembly request.

Request a Parts QuoteView Company News

Separate the four component references

The Mud Pump Crosshead product reference contains a multi-model parts table. Its F1300/F1600 columns label the two reference sets “Old Model” and “Model”. The selected entries below retain those labels and the original numbers.

Selected entries from the catalogue's F1300/F1600 columns

This is a catalogue comparison for the stated columns, not a universal interchange list for every F-series pump. Preserve the number shown on the installed equipment's drawing when asking for a replacement.

Match the model and drawing revision

Start with the manufacturer, complete pump model and available nameplate details. Then locate the crosshead section in that pump's parts drawing. Record the component position and any suffix as well as the main number.

The broader BOMCO F-series parts category includes other pump components. If the request is for an F1600, the F1600 identification checklist helps organise the model and assembly information. A similar model name alone does not establish the required crosshead reference.

Make each purchase line specific

State whether the request is for the crosshead body, pin, upper guide plate, lower guide plate or a combination of these parts. If an assembly is required, list the components expected with it rather than using “crosshead set” without a scope.

Include photographs of the existing component and its position in the assembly. Add dimensions from the drawing or measurements already available, and identify which surface or feature each measurement describes. These details support a parts review without relying on appearance alone.

Information to send for quotation

  • Pump manufacturer, complete model and nameplate photo.
  • Component name, drawing number and drawing revision.
  • Marked assembly drawing and available component photos or dimensions.
  • Quantity for each purchase line and delivery destination.

Use the part and drawing number search to find an existing reference, then retain the complete code in your inquiry.
