PDF page numbers count from the first page of each reference file. Brand names identify the equipment or catalogue source. Send the nameplate, complete reference, quantity and drawing revision for a parts review.

The Honghua 3NB-2200F section uses a separate fluid-end arrangement from the smaller F-series models in the reference bilingual catalogue. It distinguishes the suction and discharge cylinders, their seals and the associated valve components. Start a 2200F enquiry with that arrangement rather than extending a smaller-model reference by horsepower alone.

Read the assembly and material-code scope together

The cylinder-detail page lists 1200009099 for the clamp assembly, while the fluid-end assembly list identifies 1200009003 for the discharge manifold. Separate pages describe a high-pressure valve assembly and a ribbed-valve assembly. These are source configuration groups and should not be combined into a generic valve kit without identifying the installed type.

Configuration details to confirm

The source model is 2200F. This guide follows the 3NB-2200F designation printed in the source section. Confirm any HL configuration using its own nameplate and parts catalogue. Keep the source model wording, liner size and valve arrangement with the material code. Pressure suitability must be checked against the actual pump and component rating; a catalogue-wide maximum is not a rating for every liner or assembly.

Information for a replacement-parts enquiry

Provide a readable nameplate photograph, pump serial number, the catalogue cover or revision, the material code, source page, item number and required quantity. Add photographs of the removed component and its markings. For threaded parts, include the thread form and measured dimensions; for seals, include the actual sealing profile as well as the nominal size.

The reference list distinguishes a complete assembly from its individual components. State whether the request concerns one component, a matched set or a complete assembly, and identify any parts that must remain paired. Codes printed for standards, equipment models or consumable grades have a different role from a custom part identifier.

For related selection information, see our mud pump spare-parts supply guide. Send the model and component details through the Pratt Oil contact page for a quotation review. Supply and suitability require confirmation against the submitted details.
