Honghua HH2400 Pump Parts and NB033 Material Codes

Published by Pratt Oil · 21 October 2026

Use the NB033-TC catalogue to identify HH2400 material codes, component descriptions and the source configuration before requesting replacement parts.

Selected drawing referencesPart Number ReferenceMud pump spare parts

For a Honghua HH2400 pump parts enquiry, identify the component using the material code and assembly shown in the NB033-TC catalogue. The December 2021 parts book separates the frame, crankshaft, pinion, crosshead, fluid end, suction and discharge modules, piston rod and guard assemblies. The model name by itself is not enough to select a replacement.

Material codes and drawing callouts serve different purposes

The HH2400 tables have separate columns for item number, code, component name, specification and quantity. The ten-digit values in the code column are presented here as material codes. A numbered arrow on the sectional illustration is an item callout; it is not the ten-digit purchasing code. Keep the two fields together when marking an assembly drawing.

For example, the main-body list on PDF page 7 associates 1200726797 with the frame assembly, 1200726796 with the crankshaft assembly and 1200726803 with the pinion assembly. The same page lists five crosshead component assemblies under 1200726810. These are identifiers from the NB033 configuration, rather than a universal code list for every Honghua pump.

Identify the fluid-end assembly and its individual modules

The main list identifies the fluid-end assembly as 1200725917. The detailed suction-module table on PDF page 21 gives 1200725915 for the suction module; the discharge-module table on page 22 gives 1200725904 for the discharge module. A request for the complete fluid end should therefore be distinguished from a request for one module, stud, seal or flange.

Send a marked drawing or a clear photograph of the component and its connections. For studs and nuts, include both thread forms and the required length. For seal and valve components, identify the installed assembly and the specification on the relevant drawing. Do not select a component solely because a photograph looks similar.

Metric piston-rod references need their complete assembly context

PDF page 23 is explicitly headed as the metric piston-rod assembly. It lists rear section 1200596893, front section 1200682885 and set screw 1200596896. State whether the request is for a complete rod or an individual section, and include the pump serial number and measured connection details. A metric label on one assembly does not establish the thread form of every other component in the pump.

Prepare an HH2400 spare-parts request

  • Identify the pump as HH2400 and provide its nameplate and serial number.
  • Include the NB033-TC catalogue revision, assembly page and item number.
  • Copy the full material code as printed, with the component name and quantity.
  • Attach photographs and the relevant drawing, including any site modification.
  • State the delivery destination and any inspection or documentation requirements for review.

The table below makes the checked source references available as text and a downloadable CSV. The catalogue quantity records the quantity shown in that assembly; it is not a stock level or an order quantity recommendation. Contact Pratt Oil about mud pump spare parts with your actual component information so that matching and supply can be reviewed.

Wear-part references outside this catalogue

The note on PDF page 20 directs the reader to the user manual for individual liner, piston and liner-seal details. Those missing identifiers have not been inferred from the main assembly code. Include the applicable user-manual page or the installed component drawing for a wear-part request.
