Honghua HHF-1000 spare-part identification can begin with the GH 3101 drawing family in the July 2007 parts list. The book separates the frame, crankshaft, pinion shaft, crosshead, fluid end, lubrication, spraying and discharge equipment. Preserve the exact code printed for the required component instead of selecting a part from the 1000 designation alone.

Use the drawing family without losing its suffix

The general assembly list names GH 3101-03.00 as the pinion-shaft assembly. Its component table identifies GH 3101-03.02B as the widened pinion shaft. The final B and the assembly context are therefore useful identification details; a shortened reference that omits the suffix does not reproduce the source entry.

The crosshead table also prints references such as GH 3101.04.01 with dots. These original forms remain in the reference list. Keep the source page with the code where punctuation differs between the cover, assembly title and component table, rather than silently assuming a revised identifier.

Separate custom parts from standard hardware

Some rows use a GH drawing number, while others cite a GB/T standard, a pressure-gauge model or a sealant grade. The book also specifies American-standard fasteners by dimensions without giving a unique Honghua code. For these rows, the thread, length and applicable item description are essential; a standard designation by itself is not a unique pump spare-part number.

For liners, pistons, valve components and seals, include the installed size and construction. For a widened pinion or bearing-related enquiry, add the mating-part information and clear photographs of the actual markings. Distinguish a complete assembly from a bare component so that the quotation scope is clear.

Prepare a source-specific request

Send the nameplate and serial number, catalogue date, complete drawing reference, item number and quantity. Include the relevant source page and photographs of the removed component. The book identifies the pump as HHF-1000. Confirm its nameplate and GH3101 drawing family before selecting a replacement.
