Honghua HHF-1600HL Parts: Matching the NB1600M.00H Catalogue

Published by Pratt Oil · 21 October 2026

Use the HHF-1600HL NB1600M.00H parts book to identify fluid-end, power-end and valve parts by drawing number and material code before ordering.

For an HHF-1600HL spare-parts enquiry, start with the catalogue designation NB1600M.00H when it matches your equipment documentation. The December 2015 English parts book uses this assembly designation and combines NB100 power-end references with NB1600M fluid-end references.

This is a configuration-identification guide. It does not establish that another parts book labelled 3NB-1600HL, NB1602 or HTNB161 describes the same installed components.

The material code and drawing number serve different identification roles. Quote both when they are available, and retain the final letters: H, HA and other suffixes are part of the printed reference.

Suction and discharge cylinders need their own references

The top-level fluid-end table identifies suction-cylinder assembly NB1600M.01.01.00HA with material code 1200079512. Its detailed table lists suction cylinder NB1600M.01.01.01HA, code 1200079513. The discharge-cylinder assembly is NB1600M.01.06.00HA, code 1200079514; its cylinder is NB1600M.01.06.01HA, code 1200079444.

A cylinder body and a cylinder assembly are different enquiry items. State whether you need the body, an assembled unit, or a specific stud, nut or seal, then attach the corresponding exploded-view item number.

Valve components and material codes

The valve assembly is identified as NB100.05.11.00. Its component list associates valve body NB100.05.11.01 with code 1200357788, valve seat NB100.05.11.06 with code 1200357793, and valve guide frame NB100.05.11.07 with code 1200357794.

Keep a valve body, rubber insert, seat and guide cage separate in the enquiry. A valve-family reference does not establish the size, material or installation arrangement of every component in a different fluid-end version.

Check threads and units rather than converting the catalogue number

The source contains both metric standard designations and inch-thread component descriptions. For example, the suction-cylinder table lists nut NB1600M.01.01.03H as 1-8UNC-2B(SPL). Send the complete printed thread form, together with the matching stud reference, rather than replacing it with a metric approximation.

Where a description mixes a thread designation with an unlabelled length, verify the dimensions from the drawing or the removed part. Do not derive the working pressure, flow rate or component interchangeability from the model name alone.

Prepare an enquiry that identifies the installed configuration

  • Photograph the pump nameplate and the parts-book cover.
  • Quote NB1600M.00H only when it is supported by your equipment documents.
  • Provide the drawing number, material code, item number and required quantity.
  • Attach photographs and dimensions for the actual liner, piston, valve, cylinder or fastening item.
  • Identify the assembly required and any differences between the installed part and the drawing.

See our mud pump spare-parts information when preparing a quotation request. Matching remains subject to the complete equipment and component details.
