The NB005 quintuple pump parts list identifies the complete assembly as NB005.00. It uses exploded illustrations to link numbered callouts with component descriptions, drawing references and assembly quantities. For replacement-part purchasing, include the assembly drawing as well as the individual reference; a shared prefix alone does not prove that two components are interchangeable.

Start with the relevant assembly drawing

The main table on PDF page 2 identifies frame assembly NB005.01.00, crankshaft assembly NB004.02.00, pinion shaft assembly NB001.03.00 and fluid-end assembly NB005.06.00. Different drawing prefixes appear in the same pump list. Preserve the prefix shown for the particular component rather than replacing it with NB005 throughout the request.

The five crosshead components and five connecting-rod components shown in the reference list are part of this quintuple-pump configuration. They should not be treated as a generic triplex-pump parts set. When ordering one replacement, specify its location and the required quantity rather than copying the full assembly quantity as an order.

Keep left-hand and right-hand gear references separate

The crankshaft section identifies right-hand bull-gear assembly NB001.02.01.00 and left-hand bull-gear assembly NB001.02.04.00. Their detailed pages give different gear and hub references. Send the gear drawing, rotation or position identification and the installed assembly information before requesting a quotation.

There is a source-reference difference to resolve for the crosshead: the main assembly table uses NB001.04.00, while the crosshead section heading on PDF page 8 uses NB005.04.00. Both are retained as printed. Confirm the actual component drawing and revision instead of assuming that one is a corrected spelling of the other.

Identify the fluid-end, liner and lubrication components

The hydraulic-cylinder and liner section includes liner flange Nb005.06.06, liner locking ring NB004.06.15 and related clamps, seals and studs. Letter case and the full suffix remain visible in the reference table. Include the liner bore, piston arrangement and a marked component drawing in a liner or seal enquiry; a reference in this list does not establish every size variant.

The lubrication-system pages also contain bought-in models, hose specifications and standards. A value such as a GB/T standard, a motor model or an O-ring dimension has a different role from a custom drawing number. The table labels these reference types separately. Where a source drawing-number cell is blank, no number has been invented.
