Jichai Engine Parts Catalog:
Search by Part Number

Published by Pratt Oil · 18 November 2026

Pratt Oil has added a searchable Jichai engine parts catalog with 1,295 reference entries, original part numbers and English descriptions. Find a listed component, download the reference list and prepare a clear quotation request.

1,295 reference entriesOriginal numbers · Searchable descriptions · CSV download
Open the parts catalog ↗

What you can find in the catalog

The list includes cylinder-block and cylinder-head assemblies, piston and connecting-rod components, crankshaft and valve-train references, pumps, filters, gaskets, pipework, instruments and service tools. Gas-line and mixer references also appear in the list, so it should not be treated as a diesel-only catalog.

Each row keeps its original part-number string and English description. Repeated entries remain in their original order. The 1,295 figure counts reference rows, rather than 1,295 distinct part numbers or items held in stock.

Search the complete number, then read the description

Open the Jichai engine parts reference table and enter a part number or an English component name. The prefix filter can narrow the list to number families such as 12VB or 1512T; it is a browsing aid, not a declaration that every item fits the same engine.

The table preserves periods, letters and suffixes in the displayed reference. Select a part number to open a direct link to its row and carry that reference into the quotation links. Keep the listed description with the number when preparing a purchase list.

Download a spreadsheet for a multi-item inquiry

Download the CSV parts reference and open it in Excel or another spreadsheet application to filter and mark the items you need. The download contains the same retained entries as the online table. Add your required quantity for each line and keep the original number intact.

If the source description is blank, the online table says so. No replacement description has been guessed. Send a photograph, drawing or your equipment documentation to clarify that item.

Information to include with your request

  • Engine model and serial number, with a clear nameplate photograph.
  • Original part number, listed description and required quantity for each item.
  • Drawing revision, component photographs or dimensions where available.
  • Delivery destination and requested schedule.

Pratt Oil will review the identification and requested supply scope before quoting price, availability and delivery. An engine photograph or a similar-looking number is not enough to confirm fit.

Request a quotation on WhatsApp or email 2000@pratt-oil.com. You can also use the site-wide part-number search for other oilfield equipment references.
