Start with the assembly, then identify the component

The September 1998 parts list identifies the complete pump drawing as PL 1294000. Its bill of material distinguishes the studded discharge module from the suction module and lists the liner bushing, liner clamp, valve cover and seal retainer separately. A description such as "fluid-end kit" therefore needs a breakdown: the required module, installed fittings and individual wear components should each be named in the request.

Piston rods also need attention. The same source lists 1294147 for pistons of 4 inches and larger, while 1294149 is described for 3-inch and 3-1/2-inch pistons. This is a reason to record the installed piston size and rod arrangement rather than select a rod from the pump model alone. An assembly number and an individual component number should remain separate lines in the purchasing list.

Details to include with the parts request

For a quotation review, send the nameplate, pump serial number, catalog edition, drawing number, item number and required quantity. Include clear photographs of the removed component and any stamped or cast markings. For liners and pistons, add the installed size and sealing arrangement. Mark whether the requirement is an individual part or a complete assembly; this helps avoid an incomplete comparison between quotations.
