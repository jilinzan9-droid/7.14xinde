UNBT-1180L1 Mud Pump Parts: URBO Drawings and Liner Identification

Published by Pratt Oil · 20 October 2026

UNBT-1180L1 mud pump parts need the catalogue family as well as the pump model. The URBO catalogue names УНБТ-1180L1 and lists pump assembly 44024.53.055СБ. Its 44024 / 44013 / 44040 component references must not be silently replaced with similar numbers from another catalogue.

The supplied 2004 operating manual describes L1 as the version with a base frame and L2 as the version without it. That is a source-specific configuration distinction; serial number, manufacturer and edition still need to be checked for a replacement order.

Use the URBO drawing family consistently

In the URBO breakdown, the hydraulic block is 44024.53.005СБ and the transmission shaft is 44024.53.105СБ. The liner entries use the 44040.53.034 family, with a different suffix for each bore. A source suffix is part of the reference, not decorative text.

The supplied Bulanash catalogue also covers L1 / L2, but uses a different set of drawing references. Similar model names and component functions do not establish a cross-reference between those catalogues. Send the original drawing or the catalogue page for the installed unit.

Check the wet-end set before ordering consumables

Retain the original characters in a reference, including the Cyrillic letters СБ where shown. Similar-looking Latin letters or an omitted suffix can make a quotation ambiguous. The references identify entries in these catalogues; they do not prove that a replacement from a different edition will fit.

Information to include in a parts enquiry

  • Complete pump designation, manufacturer shown on the nameplate, serial number and year.
  • Original drawing or catalogue reference, including every suffix and the figure / position number.
  • Part photographs, key mating dimensions and the assembly in which the part is installed.
  • For fluid-end consumables: liner bore, piston construction, seal arrangement and required quantity.
  • Delivery destination and the list of parts required for the same maintenance job.

For a UNBT-1180L1 enquiry, send the reference together with the pump details for identification. See our mud pump spare parts enquiry page or UNBT series parts catalogue. Availability and suitability require confirmation for the actual configuration.
